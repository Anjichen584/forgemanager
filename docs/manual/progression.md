## 五、师徒（v2.0）

- **拜师**：`/zhujian master 玩家名` 向在线玩家发邀请，对方 `/zhujian accept` 收徒，邀请 60 秒有效（仅内存，重启失效）。
- **名额与限制**：一人只能有一个师父；师父徒弟数上限 `mentor.max-disciples`；禁止循环师承。
- **解除**：徒弟 `/zhujian master leave`；师父 `/zhujian master expel 徒弟名`。解除后徒弟进入冷却（`mentor.unbind-cooldown-hours`），冷却中不能再拜师。
- **分成**：徒弟每锻成一把剑，师父得徒弟本次剑币收益 × `coin-share-rate`。只在徒弟锻造时结算，**师父离线也照常入账**（只要仍是绑定关系）。
- **容差加成**：师父**在线**时，徒弟加热容差 ×(1 + `apprentice-tolerance-bonus`)，默认 +5%，与专精容差叠加；师父离线无加成。
- 离线、删号不报错：全部按 UUID 查询，查不到名字时显示 UUID 前 8 位。

## 六、成就与匠衔段位（v2.0）

- **成就**：20 项，按锻造次数、无瑕、剑币、声望、专精、委托、剑灵、剑冢、图鉴、钢纹、师徒、成就数等指标判定，达成后发剑币与积分。`/zhujian achievements` 打开界面。
- **匠衔段位**：按声望（或专精等级，`craft-rank.basis`）划档，跨档广播。赛季切换时回落 `season-fall` 档。
- 段位名称与门槛在 `craft-rank.tiers` 配置。

## 八、剑灵、剑冢、世界事件、剧情

### 剑灵（`/zhujian spirit`）
- 击中敌人养灵（`spirit.gain-per-hit`），`spirit feed` 花剑币喂养，`spirit name 剑名` 起名（存 PDC）。
- 灵性分档（初醒 / 通灵 / 凝魄 / 化灵 / 神器），高档解锁灵契额外词条（最多 `max-extra-affixes` 条）。

### 剑冢（`/zhujian tomb`）
- `tomb bury` 埋剑入冢（全服广播可关），`tomb list` 或 GUI 看列表，`tomb info 编号` 看详情。
- `tomb challenge 编号` 付费挑战复刻，成功得剑币与声望，失败扣声望且挑战费不退。
- `tomb take 编号` 取回（`owner-can-retrieve` 与 `retrieve-fee` 可配）。


### 世界事件（`/zhujian event`）
- 按 `events.interval-minutes` 定时开一场（默认 60 分钟，持续 180 秒），也可由管理员 `event start <id>` / `event stop` 手动控制。
- 当前类型包括：陨星降临（`meteor`，地面刷星材）、矿脉（`veins`）等。`event` 无参数看当前状态。

### 剧情（`/zhujian story`）
- 按锻造、委托、剑币等进度推进章节，`story` 查看当前章节。

## 九、委托、比试、耐久、声望、剑谱、大赛、材料分级

- **委托**（`board`）：板上同时挂 `commissions.slots` 张（最多 3），按条件（品质、词条、折叠层数、评分）交货换声望与剑币，`expire-hours` 小时过期作废。
- **比试**（`duel <玩家>`）：同剑胚、同种子比总分，胜者 +25 声望、败者 +6；`duel accept` 应战，`deny` 拒绝，60 秒有效。
- **耐久与研磨**（`repair`）：每刀扣 `durability-loss-per-hit`，归零崩刃；研磨消耗材料，稳住刃压恢复耐久。
- **声望与称号**：每锻一把给 `评分 ÷ 3.5` 声望；学徒 / 匠人 / 宗师 / 大匠 / 铸剑圣手（0 / 100 / 300 / 800 / 2000）。
- **剑谱**（`record` / `manual` / `copy <谱号>` / `copy stop`）：登记成品为剑谱，临摹时同种子复刻，按复刻度给声望。`manual-max-entries` 限制谱库数量。
- **锻造大赛**（`contest`）：默认每 30 分钟一场，每场 5 分钟，全员同一份火候；`contest start` 强开，`contest list` 看榜。
- **材料分级**（`grade`）：普通 / 精炼（+6%）/ 天外（+12%，+1 词条），锻造时优先消耗高档料。

## 十、专精等级与匠人天赋（v2.9）

### 10.1 经验与曲线

每锻一把给经验：

```
经验 = gain-base + gain-per-quality × 品质序号 + gain-per-score × 评分
     = 6 + 5 × 序号 + 0.05 × 评分                    （默认）
升级 = curve-base + curve-per-level × 当前等级
     = 120 + 55 × Lv                                 （默认）
```

v2.9 把这条线砍陡了一刀。原来一次锻造 `10 + 8×序号 + 评分÷10`（精良 75 分约 34），
曲线 `80 + 40×Lv`；现在同样一把只有 20，曲线也抬高 25%。粗算（精良 75 分，不含勤学）：

| 目标 | v2.8 需要锻造数 | v2.9 需要锻造数 |
| --- | --- | --- |
| Lv.5 | ~9 把 | ~22 把 |
| Lv.10 | ~70 把 | ~155 把 |
| Lv.20 | ~240 把 | ~470 把 |

觉得太快 / 太慢直接改 `progression.*`（改完 `/zhujian reload` 生效，不用重启）。
**老玩家的等级与经验不会掉**，只是下一次锻造时按新曲线补级。

### 10.2 等级加成（原有）

高温容差每级 +1%（最多 +30%），Lv.8 起命中区 +1，叠钢时间与开刃绿区随级提升，
Lv.10 起额外词条概率每 5 级 +10%（最多 +60%）。

### 10.3 匠人天赋（v2.9 新增）

每 5 级给 1 点，60 级共 12 点；七项全点满要 20 点，**必然要取舍**：

| id | 天赋 | 上限 | 每点效果 |
| --- | --- | --- | --- |
| `touch` | 手感 | 3 | 加热容差 +3% |
| `eye` | 眼力 | 2 | 锻打命中区 +1 格 |
| `ember` | 控火 | 3 | 降温速度 -6% |
| `fold` | 稳手 | 3 | 叠钢时限 +0.4s |
| `edge` | 刃感 | 3 | 开刃绿区 +0.8 |
| `luck` | 火候 | 3 | 额外词条概率 +6% |
| `study` | 勤学 | 3 | 锻造经验 +8% |

- **开局固化**：天赋在开工那一刻读进会话，中途升级 / 洗点不影响当前这一炉（跟图纸、环境修正一致）。
- **洗点要钱**：`talent.reset-cost`，默认 2000 剑币，且要 `reset confirm` 二次确认——
  否则「先点勤学练级、练满再洗成战斗力」就是零成本。
- **跨重启保留**：分配存在 `data.yml` 的 `talents` 子段。赛季导致等级回落时不回收已点，
  但可用点数按当前等级算（会出现 0 可用），练回来才能继续点。
- 面板里每一项都带进度条与当前合计，`/zhujian talent` 一眼能看出「还差几点」。

```
/zhujian talent                  # 面板：等级 / 已点 / 可用 / 七项进度 / 当前合计
/zhujian talent add touch        # 加一点
/zhujian talent reset            # 先报价
/zhujian talent reset confirm    # 真洗
```
